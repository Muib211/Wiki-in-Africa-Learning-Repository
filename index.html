About

About this catalogue

This catalogue makes Wiki In Africa training and learning resources searchable and filterable, sourced from the Wiki In Africa Wikibase.

Resources are organised by campaign, skill level, project, format, language and topic, and refresh automatically from the Wikibase on a schedule.

Contributing

How to contribute

Add or improve a resource

Visit wikiinafrica.wikibase.cloud and log in to add new resources or improve existing ones.

What makes a good resource entry?

  • Campaign — which programme the resource belongs to.
  • Skill level — beginner, intermediate, or advanced.
  • Format, language, and topic.
  • Creator and a link to the resource.

Use the Improve data filter in the sidebar to find resources missing any of these fields.
